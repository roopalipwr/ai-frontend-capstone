# AI Frontend Capstone

This repository contains the Frontend AI Engineering capstone project. 

## Project Description

The AI Frontend Capstone is a comprehensive web application developed as the final project for the Frontend AI Engineering track. The project is structured into incremental milestones, starting with core repository establishment and progressing to full-stack, AI-powered frontend features.

### FE-01: Setup Phase Goals

The primary goal of the initial setup phase (`FE-01`) is to establish a solid, organized, and standardized foundation for future development:
- **Repository Setup:** Formulate a clean directory structure with standard ignore rules and open-source licensing.
- **Workflow & Standards:** Define strict coding guidelines, accessibility standards, and AI development principles.
- **Git & Commits Standardization:** Establish structured collaboration standards via Conventional Commits.

---

## Technology Stack

The project starts with core web technologies, with framework decisions to be made and integrated in subsequent development phases.

- **Languages:** HTML5, CSS3, JavaScript (ES6+)

## Development Workflow

To ensure high-quality and consistent contributions, all development must adhere to the conventions defined in `GEMINI.md`:

### Coding Conventions
- **Clean Code:** Write highly readable, self-documenting code with meaningful names.
- **Simplicity:** Prioritize explicit, straightforward solutions over unnecessary architectural complexity.
- **Accessibility:** Adhere strictly to WCAG accessibility best practices.
- **Focused Scope:** Keep changes minimal and isolated.

### Commit Guidelines
We use [Conventional Commits](https://www.conventionalcommits.org/) to structure our Git history:
- `feat: ...` for new features
- `fix: ...` for bug fixes
- `docs: ...` for documentation changes
- `chore: ...` for updating project configuration and build tools

## Getting Started

### Prerequisites
- [Git](https://git-scm.com/) installed on your local machine.

### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/roopalipwr/ai-frontend-capstone.git
   ```
2. Navigate to the project directory:
   ```bash
   cd ai-frontend-capstone
   ```
3. Explore the configuration and instruction files:
   - Read `GEMINI.md` to understand the AI instructions and conventions.
