# Case Study 1 — FE-04 AI-Assisted Workflow Comparison

## The Problem

I needed to build a small settings-form feature while demonstrating how the way I instruct AI affects the development process. The assignment required me to create the feature twice: first with a vague workflow and then with a more precise workflow, so I could compare the results.

## What I Did

I built a settings form using HTML, CSS, and JavaScript. The form included profile settings, password validation, notifications, and theme preferences. I created the first version using a vague AI workflow and then created a second version with clearer requirements and verification steps. I kept the two versions on separate Git branches and compared the changes. I also documented the differences in `WORKFLOW.md` and tested the validation behavior.

## What Came of It

The comparison showed me that clearer instructions gave me more control over AI-assisted development. I saw the difference between the vague and precise workflows by reviewing the two branches and their changes. I learned to define requirements clearly, verify the implementation, and compare the result against the original task instead of simply accepting AI-generated code.



# Case Study 2 — FE-01 AI Frontend Capstone Setup

## The Problem

I needed to set up the foundation for my AI Frontend Engineering capstone project before working on larger features. The assignment focused on creating a clean repository and establishing clear instructions for using AI during development.

## What I Did

I created the GitHub repository and added the basic project files, including the README, MIT license, `.gitignore`, and `GEMINI.md`. I documented the project description, technology stack, development workflow, coding conventions, AI instructions, and Git commit conventions. I used Gemini as my AI assistant and reviewed the changes instead of accepting them without checking.

## What Came of It

I finished with a structured project foundation that I could build on for later assignments. I also learned how to give an AI assistant project-specific instructions and how to review AI-generated changes before using them in my project.
